# 再開方法

## オーナーが入力する短い指示文
回答がないとき：
```
Sö-dä fuüの続きをお願いします。README.md → ops/progress.md → ops/questions.md の順に読み、「次の手順」の一番上から進めてください。
```
回答や実機確認の結果があるとき（下の2行を書き換えて足す）：
```
回答：1はこのまま、2は500円、8は受け付けない
実機確認：A1◯ A2◯ A3×タイトルが3行になった
```
- 上の2行は**例**です。書き換えずにそのまま送られた場合は、未回答として扱います。

## 再開時に責任者がやること
1. `ops/progress.md` の「次の手順」と、`ops/questions.md` の回答を確認する。
2. フォントを入れる：Zen Maru Gothic を ~/.fonts にダウンロードし、`fc-cache -f` を実行する。
3. 作業ブランチ `claude/soda-fuu-product-prototype-r1bw3p` で作業する。
4. 区切りごとに `ops/progress.md` を更新し、commit・pushする。
5. 試作品と確認結果がそろったら、報告書を書いて終える。

## 定期実行について
- 今回は、定期的に自動で動く仕組み（スケジュール実行）は**設定していない**。
- 寝ている間に動かしたい場合は、オーナーが希望すれば、Claude Codeの「スケジュールされたタスク」で、上の指示文を決まった時間に実行する設定ができる。
  - 料金の追加はないが、利用枠を使う。
  - 設定するかどうかは、オーナーの確認後に決める。
