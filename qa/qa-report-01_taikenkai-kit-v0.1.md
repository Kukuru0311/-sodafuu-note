## 機械的な点検（修正後に再実行）
- zip：破損なし。日本語ファイル名のUTF-8フラグあり。13ファイル、約5.4MB（noteの上限50MB以内）。
- pptx：3ファイルとも再読み込みできる。サイズは、Instagram用が1080×1350px相当、チラシがA4。テーマのフォントもZen Maru Gothicに設定した。
- PDF：ガイドは5ページ、チラシ見本は2ページ、無料サンプルは1ページ。すべてA4で、フォントは埋め込み済み。
- 画像：Instagram見本は1080×1350px（修正前は1351pxだった）。見出し画像は1280×670px。
- 日付：2027年1月9日・16日・23日は、すべて土曜日。

## 指摘と対応
### 重大（3件 → 今の環境でできる修正は完了。実機確認が残る）
1. チラシ最下行が、家庭用プリンターの印刷できない余白にかかる
   - 対応：済み。「ひとこと」を申し込み枠の中へ移した。枠の下端は紙の端から約16mm、文字は10pt以上。
2. 写真の差し替え方法が説明されていない
   - 対応：済み。ガイド3ページに「写真の入れ方」「写真がないとき」を追加した。
   - 未検証：iPhoneのKeynoteでの実際の操作
3. フォントの置き換わりで見た目が変わる
   - 対応：一部済み。
     - フォント本体（OFL、ライセンス文つき）をzipに同梱し、パソコンでの入れ方を記載した。
     - iPhoneでは表示が変わることを、記事とガイドに明記した。
     - 新しく足した文字も同じフォントになるよう、テーマのフォントを変更した。
   - 未検証：実際のKeynote・PowerPoint・Googleスライドでの崩れ → **オーナーの確認ポイント1**

### 中（13件 → すべて対応）
- Instagramに「しめきり」がない → 2枚目の申し込み欄に追加
- みかん色の項目名が読みにくい → 項目名を濃い色に変え、帯の上の白文字を太字にした
- チラシの文字が小さい → 項目を12pt、申し込みを11ptに上げた
- 文字が増えると重なる → 「場所」の見本を短くし、ガイドに「1項目1〜2行まで」を追記
- 「記念価格」の表現 → 「販売テスト中の価格です。内容を追加したときに見直すことがあります。」に変更
- チラシのpptxに2色が入っている説明がない → ガイドに「使わない色のページを消して保存」を追記
- 白いふちが出る説明がない → ガイドに追記
- QRコードの作り方がない → ガイドに追記
- 教室名が実在するかもしれない → 「○○おえかき教室」に変更
- 「3〜6さい（未就学）」が1月の時点で合わない → 「3さい〜年長さん」に変更
- 投稿手順の未確認事項 → アプリの最新版化、未確認の明記、Safariでのダウンロード方法、出典の書き方、振込申請を追記
- お問い合わせ先があいまい → 「この記事のコメント欄から」に変更
- 「文字を入れ替えるだけで完成」は言い過ぎ → 「文字と写真を入れ替えて使えます」に変更
- 無料サンプルPDFのページ番号 → ページ番号なしの1ページ版を別に作成

### 軽微（主なもの）
- 表記ゆれ：「申し込み」「おしらせ」「体験会のおしらせキット」にそろえた（ボタン名などの「申込」は使っていない）。
- DM文例：しめきり・場所・終わりの時刻を追加し、変な改行も直った。
- 記事に、みかん色のInstagram見本を追加した。
- 行頭の全角スペースでの字下げは、記事から削除した。
